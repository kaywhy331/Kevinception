# Changelog

## 0.7.0

- Migrated to Next.js App Router and static export.
- Added one persistent React Three Fiber canvas for the six-year experience.
- Added procedural 3D environments for KevinVision, Kevin Online, KevinBook, KevTok, Kevin Nexus, and Kevin Echo.
- Preserved the V6 functional applications as the focused DOM interface layer.
- Added authored camera movement, cross-year transition effects, settings, WebGL fallback, text mode, and persistent artifact discovery.
- Added semantic portfolio, work, resume, about, and contact routes.
- Added Windows-safe dev and preview scripts with automatic port fallback.
