## Device-framed contract

The redesign uses one hierarchy in every chapter:

`environment → physical device → operating or interaction layer → era application → content`

- 1990 and 2000 remain the physical-reference chapters.
- 2010 uses a laptop, Windohs 7, and KevBook.
- 2020 uses a mounted phone, KevOS, and KevTok.
- 2030 uses a multimodal Nexus orchestration console with five roles and a human gate.
- 2040 uses Kevin Echo as a holographic projection with optional voice, compact text fallback, and disclosed provenance.

Voice is optional. Keyboard, touch, and text paths remain available. The application iframe is always clipped by its device viewport in the visual experience; explicit text mode remains available as the accessible full-page alternative.
