# Archive

Point-in-time planning baselines, audits, and work receipts. They are kept for history and are **not** maintained; where they disagree with the living docs in `docs/` or with the code, the living docs and the code win. Chapter names in these files often predate the current ones (for example KevinBook, Kevin Nexus, Kevin Echo, Kevazon Marketplace); see `../NARRATIVE.md` for the names in use.
